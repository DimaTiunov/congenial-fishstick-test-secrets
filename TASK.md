# Задание

## Контекст

Это приложение `support` для Webasyst: клиент в личном кабинете создаёт обращение с вложением, комментирует его и делится публичной ссылкой; сотрудник в бэкенде смотрит обращение и меняет статус. Код сгенерировал AI-ассистент по задаче «сделай приложение обращений с вложениями». В прод он ещё не попадал.

Проект работает на **старой версии Webasyst**, поэтому решения должны использовать только стабильный API фреймворка без новых возможностей.

Твоя задача: **подготовить код к мержу**.

## Бизнес-требования

1. Создавать обращения, комментировать и скачивать вложения могут **только авторизованные** клиенты, и только по **своим** обращениям.
2. Вложения: только `jpg`, `png`, `pdf`, **не больше 5 МБ**. Файл не должен быть доступен по прямой ссылке без проверки доступа и не должен исполняться как код на сервере.
3. Публичная ссылка на обращение: токен **случайный** и не угадывается по номеру обращения. Публичная страница показывает **только тему и статус**.
4. Клиент не может от своего имени оставить комментарий сотрудника. В закрытое обращение комментировать нельзя.
5. **Не более 3 открытых обращений** на клиента, даже при нескольких одновременных запросах. Допустимые статусы: `new` → `open` → `closed`, закрытое снова не открывается.
6. Сотрудник работает с обращениями **только с правом «Работа с обращениями»** и может менять только статус и внутреннюю заметку. Внутренняя заметка клиенту **не показывается**.
7. Текст обращений и комментариев везде выводится как текст, а не как HTML. Список обращений отдаётся порциями (не больше 50 за запрос).

## Что нужно сделать

- Найти и исправить проблемы в PHP-коде, шаблонах и JS.
- Привести код в соответствие с бизнес-требованиями.
- Объяснить, как ты проверишь, что исправления работают.

Всё за 25 минут сделать не обязательно. Расставь приоритеты: начни с самого важного.
